# Source notes

- All rows and names are synthetic fixtures created to demonstrate the report workflow.
- Grain: one row per active project.
- Forecast variance: `forecast - budget`.
- Stable rate: projects labeled `Stable` divided by all projects.
- The three `At risk` projects contribute $820,000 of the $850,000 portfolio overrun.
- Chart map: “Forecast variance by project” uses a category bar chart because the question is a signed comparison across eight projects. The exact values remain available in the audit table and semantic fallback.
- No richer trend is included because the fixture has one current snapshot rather than enough observed periods for an honest time-series chart.
