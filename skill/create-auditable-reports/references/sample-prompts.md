# Sample prompts

## Build a new report

> Use $create-auditable-reports to analyze these files and create an executive HTML report. The decision is whether the portfolio is ready for month-end sign-off. Use May 31 as the cutoff, show the largest exceptions, and preserve the SQL and source notes.

## Add a print edition

> Create a separate print-ready HTML from the existing report. Keep the interactive report unchanged. Use Letter landscape and remove scripts, tooltips, dialogs, buttons, and expandable sections.

## Reconcile a workbook to a database

> Compare both workbook tabs to the database by project. Identify the most defensible control totals for costs, billings, revenue, contracts, budgets, change orders, and forecast. Enforce the stated cutoff in accounting/source dates and call out extracts that extend beyond it.

## Revise an existing report

> Add a section explaining the three largest forecast exceptions. Preserve every existing section, source, chart, table, and caveat unless the new section directly requires a narrow update.

## Technical validation report

> Build a technical report that validates the migration extract. Lead with the result, then document key completeness, duplicates, cutoff logic, reconciliation tolerances, unsupported fields, and reproducible queries.
