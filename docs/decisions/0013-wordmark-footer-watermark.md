# Decision 0013: Use the full wordmark for the print footer watermark

- **Status:** Accepted
- **Date:** 2026-08-06
- **Scope:** Branded Paged.js print editions

## Decision

Use the full Incursa wordmark as a small, low-opacity fixed watermark in the
lower-left print margin. Keep page numbering in the lower-right margin and do
not add a separate text brand footer or a second mark watermark.

## Rationale

The full wordmark identifies the company more clearly than the standalone N
mark while remaining quiet enough for forms, agreements, and reports. A single
footer treatment reduces visual furniture and keeps the page edge consistent.

## Consequences

- Print output no longer repeats the brand name as running footer text.
- The mark asset remains part of the approved branding set for future use, but
  is not embedded in this print footer treatment.
- Existing wordmark header branding is unchanged.
